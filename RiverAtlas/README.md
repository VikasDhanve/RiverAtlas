# RiverAtlas Showcase 使用说明

大连市自然资源统一确权登记工作市级确权项目汇报，v1.4.0星空、画面精简与立体图层改版。支持集团测绘院及孙颖汇报材料编制。

## 打开方式

交付目录已从“HTML演示页”改名“RiverAtlasShowcase”。上级目录双击`RiverAtlasShowcase.html`打开完整演示，也可使用第三页/第七页快捷入口；本目录工程入口仍为index.html。2026-11-06项目迁移到D:/WorkSpace Development/AppResource/RiverAtlasShowcase，历史压缩包和备份已按用户要求删除，版本改由GitHub私有仓库管理；原始素材位置不变。

直接双击本目录的 `index.html`，推荐桌面Chrome或Edge。无需安装Node、无需联网、无需启动服务器。也可从上一级目录打开“打开演示稿.html”。请整体复制工程目录，保持src和assets的相对位置。

从GitHub完整克隆或下载后同样双击index.html。运行时不访问CDN、在线字体、地图、统计服务或任何接口。

## 本轮效果

主画面精简了重复标题和操作提示，说明集中在帮助；全局浅星空随鼠标产生视差，静止/暂停/静态时停止位移。第七页四层包含原稿影像和专题图，人工选层、分层/合拢、复位与原件查看，不自动轮换。图层用于资料组织示意，不是精确配准的GIS/真实三维地形；卫星平台、采集日期等原稿未提供，未补造。

## 第三页政策展陈

上级目录双击“打开第三页政策展陈.html”直接体验。第三页右侧重复标题和操作说明已移除，纸面扩大。完整政策名称在左侧宽目录；鼠标移入预览、点击固定，再次点击解除；右侧文件移入放大，移动鼠标查看细节。R或“恢复默认”回到规程。第三页播放/跳过禁用，不自动轮换或翻页；键盘/触屏可操作，完整文件可打开。

## 第二页样板

上级目录双击“打开第二页交互样板.html”可直接体验。鼠标移入文书聚焦，移开还原，点击标题/文书固定；“恢复全览”或R恢复，点击“查看完整原件”核对全件。该页播放/跳过禁用，不自动轮换或翻页；键盘Enter与触屏点击可固定。原v1.1其他页面保留。

## 演示操作

| 操作 | 方法 |
|---|---|
| 前后翻页 | 底部按钮，方向键←/→，PageUp/PageDown |
| 回到封面/末页 | Home/End |
| 章节跳转 | 顶部六章导航；“全部页面”可搜索30页标题 |
| 流程分步 | 点击“下一步”或按S；高亮表示讲解位置，不代表业务完成 |
| 播放/暂停 | 点击“播放演示”；P或空格暂停/继续 |
| 重播/跳过 | 底部按钮；R重播 |
| 全屏 | 底部按钮或F；Esc退出。浏览器限制时可用F11 |
| 静态模式 | 底部“静态”或A；系统减少动态效果自动生效 |
| 原稿资料 | 对应页完整文字/表格/原图；还可查看全部35页和全部39个业务原件 |
| 图件专注 | 点击“专注图件”收起标题与讲解栏，再点“显示讲解”恢复 |
| 多图播放 | 数字标签直接切换；“播放演示”每3.2秒切换一份，手选中断序列 |
| 审核政策 | 第19页切换“程序演示 / 政策文件”，两张文书大幅显示 |
| 原件放大 | 点击图像，使用放大/缩小、适应窗口和滚动；Esc关闭并返回原位置 |

默认人工翻页，动画不会自动把页面翻走。首页与结束页背景持续演绎水面和山体，P暂停，R重播，跳过或静态可停止。菜单和键盘响应即时，长流程按讲解操作推进。打开原稿资料/帮助/原件或切到后台时，当前动画暂停；返回后手动继续。桌面及大屏按1600×900画布适配，手机小屏回退为纵向阅读。

## 完整工程与修改位置

- `index.html`：页面入口及控件结构。
- `src/content.js`：30页讲解编排、标题/说明、来源页、图像分组、草案图表值。
- `src/source.js`：从原始PPTX提取的35页文字、表格和图像映射。
- `src/app.js`：导航、原稿阅读、原件缩放、全屏及GSAP时间轴。
- `src/landscape.js`：水面波纹、微光、山体视差、运镜及WebGL资源管理。
- `src/landscape-texture.js`：同一背景图的离线纹理data URI，修改背景后需同步重建。
- `src/stars.js`：浅星点、指针视差、暂停/静态与按需绘制。
- `src/styles.css`：色板、字号、画布、布局及小屏回退。
- `assets/originals/`：43个原始嵌入图像，原始字节保留，其中39个业务图像。
- `assets/vendor/`：固定版本GSAP压缩运行库、未压缩源码、包说明及许可来源。
- `docs/source-manifest.json`：原稿SHA256、完整提取内容及图像指纹。
- `docs/动效编排.md`、`docs/动效改版设计补充.md`、`docs/动效改版独立审查.md`：当前编排、设计扩展与独立复核记录。
- `docs/内容覆盖验收.md`：35页来源去向和内容完整性核对。
- `tests/presentation.test.cjs`、`tests/revision.test.cjs`：10组真实浏览器、动态与降级验证。

一般内容编排更新content.js；第三页政策目录的五项名称、标题及图像映射在app.js的renderPolicyLibrary中，布局在styles.css的policy-library段；数字、单位、编号和业务状态必须有来源。缺失数据不能以0填补。增加新素材后重新核对source-manifest和覆盖表，不跳过事实复核自动覆盖旧源。

开发验证可用Node 24以上：执行 `npm ci --ignore-scripts`，然后 `npm test`。测试优先使用本机Chrome或已缓存Chromium；未安装时执行 `npx playwright install chromium`，也可设置环境变量 `RIVER_ATLAS_BROWSER` 为浏览器可执行文件。`npm run vendor`可从锁定依赖重建本地动画库。`node scripts/verify-content.cjs`检查来源覆盖和原图指纹。业务演示本身不需要上述开发工具。

## 来源与许可

原稿只读：外部项目“原始汇报材料素材”中的《大连市自然资源统一确权登记工作市级确权项目汇报-2026-5(1).pptx》。SHA256：`21524156a84243f1dbc69daf613d0291e466f91e3e6f3d528b236e26489747b5`。

封面为原稿装饰山河背景（原图带AI生成标记），动画不是大连实拍、真实GIS或流速模拟。图片来自原稿，包含地图、政府通告、签字意见、现场照片、历史资质及外地样例。仅按本次汇报授权使用，未核验公网发布或再授权条件，本工程未部署公网。原图完整保留，倒置的专家意见只旋转显示。

GSAP运行库固定为3.15.1，本地提供。其许可由[GSAP官方条款](https://gsap.com/community/standard-license/)约束，安装方式见[官方说明](https://gsap.com/docs/v3/Installation/)。技能包自身的MIT许可不替代运行库许可，原库版权标注保留。第三方库不包含在本项目原创代码权利声明之内。

## 已知限制与待确认

- 本版供业务审阅，尚无用户最终验收反馈，不能视为正式项目登记完成。
- 五河长度、面积表未填写；实际内部审核、登记审核、公告、登簿、部级提交入库进度未提供。
- 大沙河面积使用原稿公告草案数据，均带草案示例标签；公告日期/地址/电话占位未补造。
- 广西贺江公告、南京清流河登记簿是外地样例，其数字不并入本项目。历史资质图标明所示有效期至2025-05-19，未认定当前资质情况。
- 省本级办法保留原语境，未独立核验现行法规或其对市级项目的全部适用关系。
- WebGL不可用时自动保留原图与轻缓运镜；系统减少动态和静态模式停用持续运动。
- 原图为栅格图片，局部聚焦和概念分层不能替代GIS量算或三维实测。缺少真实图层、模型与数据库源文件。
- 二维码外部附图依赖网络，不属于离线资源。已保存的原件图像离线可看。
- 实际工时、现场会议大屏及遥控器表现尚待用户补充/实机确认。

最新版验证见docs/星空与立体图层验证.md、docs/星空与立体图层独立审查.md；DESIGN及侧车已记录v1.4增量。
