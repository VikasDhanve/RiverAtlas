# RiverAtlas 使用说明

大连市自然资源统一确权登记工作市级确权项目汇报。当前为 **v2.0.0，1107素材改版**，34页、7章。

## 打开方式

唯一入口：`D:/WorkSpace Development/AppResource/RiverAtlas/index.html`。双击即可离线演示，推荐Chrome或Edge。整体复制本文件夹时保持src、assets与index.html的相对位置，无需Node、服务器或网络。

## 本轮内容

以“原始汇报材料素材（1107）”内41页PPT为当前依据，章节为项目概况、调查过程、专家论证、项目审核、项目公告、项目登簿、工作总结。保留原有星空、五河离线地图、流程分步、固定预览与局部放大镜。

- 工作背景、工作目标、依据、技术单位分别编排，不再保留新稿已删除的“四类边界”主讲页。
- 五河长度更新为25.7、96.5、45、164.9、94.9 km，面积不变。1106旧长度仅在历史记录保留。
- 收集资料按部门、材料和用途列表；工作底图更新为1107原图，现势依据改为2023年全国国土变更调查成果。
- 新增市级协调与县区数据比对，碧流河成果改为新稿三张成果图与调查表。六类成果在前、23人项目组织在后。
- 专家页删除新稿不再出现的历史资质，保留签字意见与两张会议照片。
- 单列外部审核，登记簿采用1107版六张图原序，新增三方面工作总结。

当前共43个图像入口，其中42份业务/流程原件可打开，另1份为既有装饰背景。底图图集其余三张专题资料仍来自1106补充PDF，其中三调资料明确标为前期资料。

## 操作

| 操作 | 方法 |
|---|---|
| 翻页 | 底部按钮、←/→、PageUp/PageDown，Home/End回首尾 |
| 目录 | 顶部七章导航，或“全部页面”搜索 |
| 图件 | 缩略图悬停/点击选图，主图上移动鼠标查看2.5倍局部细节，点击打开完整原件 |
| 工作底图 | 第8页左侧目录/固定预览选图，图集/单图切换，保持人工控制 |
| 原件 | 放大/缩小、适应窗口和滚动，Esc关闭 |
| 流程 | 第6页下一步/S、播放、P暂停/继续、R重播、跳过 |
| 地图 | 第3页选河定位，全部/恢复全图，拖拽缩放；地图焦点下方向键平移 |
| 显示 | F全屏、A静态，系统减少动态效果自动生效 |

默认人工翻页。政策及文书展陈由讲解者控制，图集手动选择会接管多图播放；打开原件或切到后台时暂停动画。

## 维护和验证

`src/content.js`维护编排，sources统一指1107版PPT页码；`src/source.js`统一维护运行图件。`src/app.js`负责交互，`src/styles.css`负责样式。`src/supplement.js`和`src/biliuhe.js`仅保留空目录声明，历史来源清单在docs。

修改后执行`npm test`、`node scripts/verify-content.cjs`，并检查大屏截图。独立复制后可执行`node tests/package-smoke.cjs <工程目录>`。测试需要Node及已安装的Playwright，本地演示无需这些工具。可选导出工具为`python scripts/package.py`，导出目录dist不入Git。

版本管理沿用私有仓库[VikasDhanve/RiverAtlas](https://github.com/VikasDhanve/RiverAtlas)，不部署公网。检查后按项目约定提交、推送，不新增本地历史复制备份。

安全边界：HTML保留本地脚本CSP，来源文字经textContent显示，无新增网络接口、远程脚本、输入解析或运行依赖。第三方GSAP/Leaflet与地理数据许可仍见assets/vendor、assets/maps/SOURCES.md。真实会议设备、业务验收和未提供的程序进度仍需确认。
